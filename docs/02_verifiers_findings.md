# Verifier findings

From reading the competition's `verifiers/` code and running it locally. The verifier code
is the authoritative spec.

Local setup: `pip install kickmix` (1.0.0 on PyPI, cp313 wheel) runs all three verifiers.
The Kaggle dataset ships its own `kickmix.so` (SHA-256 `c66b3216…005e`, a different binary);
the organizers say the metric will move to the PyPI build.

The two builds were checked against each other (6 Nov 2026) and behave identically:
same `.kmb` bytes and SHA-256 for the invsqrt and dqi reference circuits (so the same test
seeds), same qubit and Toffoli counts, same quick-check results for invsqrt and dqi, and the
same dfthcsos sample score (3,355,599,588.3155375, submission hash `276d464f…`). Either
build is fine for local work.

## Rules confirmed from code

- **Toffolis = mean per shot of CCX, CCZ and CSWAP actually executed.** A gate conditioned on
  a classical bit counts only on shots where it fires. dqi reference: 5,725,093 mean vs
  5,725,461 static, because the per-position block is skipped when that position's record
  value is 0.
- **Q = `circuit.num_qubits`**, every qubit including inputs. Classical bits are free.
- **No Z_POW in dqi or dfthcsos.** invsqrt allows it: Clifford angles free, T angles cost
  1 T, other angles cost 0.56·log2(1/ε) + 5.3 T, with ε = π·min_margin / n_rot, where
  min_margin is the worst tolerance minus error over all x.
- **Seeds:** SHA-256 of the circuit (or of the whole dfthcsos submission), merged with a
  secret salt on the leaderboard.

## invsqrt

- The only register allowed is `x` (22 qubits); everything else is scratch and must end at 0.
- Every x in [1, 3,133,452], 64 shots each. Pass iff |phase error| ≤ 2⁻²⁴/√x turns (mod 1).
- Baseline: Q = 260, 7,735 Toffolis, 1 T, 37 rotations (ε ≈ 1.3×10⁻¹¹, about 25.6 T each),
  score ≈ 2.07×10⁶.
- The sample submission's `invsqrt.kmb` is byte-identical to the output of
  `nr_reference_circuit.py` (SHA-256 `e2bf8eb6…21e1`).
- Toffolis by stage (forward = reverse): horner 1,071; multiply_m 1,043; multiply_y0 867;
  square 442; denormalize 300; normalize 120 (110 reverse); correct 28.
- Full local verify: about 19 minutes on 2 cores (262k shots in 1.5 s).

## dqi

- Registers S0..S69 (quantum, 12 bits) and E0..E4094 (classical, 12 bits). Nothing else.
- Score = R(ε₊)·Q²·T. 0 failures → ε₊ = 8.66×10⁻⁴, R = 1.19. Must have ε₊ < 1/16.
- Baseline: Q = 1,893, T = 5,725,461 static (5,725,093 mean). The sample `dqi.kmb` (~800 MB)
  is regenerated by `dqi_reference_circuit.py` in about 7 s.

Static Toffolis by stage:

| Stage | Toffolis | Share |
|---|---|---|
| Forward EEA | 2,109,450 | 36.8% |
| Reverse EEA | 2,109,450 | 36.8% |
| Chien search + Forney | 1,437,345 | 25.1% |
| Initial shift (each way) | 30,912 | 0.5% |

Inside each EEA pass: controlled gf_mul in `sweep_positions` 1,020,852 (16,204 multiplies ×
63), c_gf_iadd 194,448, swap_a_and_b 198,246, shift_b_array_right 192,252, sweep
bookkeeping 163,800, quotient divisions about 168k.

Inside Chien/Forney: the inversion chain is 5 gf_mul × 63 Toffolis per position × 4,095
positions = 1,289,925; everything else 147,420.

Takeaways:
- **GF(2¹²) multiplications are about 59% of all Toffolis.**
- The EEA runs a full 73-position multiply sweep on every one of its 222 iterations, even
  on sub-steps that don't multiply.
- The multiplier itself (63 Toffolis) and the inversion (5 multiplies) are the other targets.
- Local verify: about 7.4 s per 512 shots on one worker, so about 25 minutes for 102,400.
  The `reaction_depth()` report runs out of memory on 7 GB; the local harness skips it
  (it isn't part of the score).

## dfthcsos

Baseline reproduced locally: **score 3,355,599,588** (about 80 s).

| Quantity | Baseline | Limit |
|---|---|---|
| error_1 | 3.19 mHa | ≤ 20 mHa |
| error_2 | **18.64 mHa** | ≤ 20 mHa |
| Λ | 308.456 | > 49.0 |
| E_gap | 3.9655 Ha | > 3.914898 Ha |
| λ_eff | 49.301 | (score factor) |
| T_total | 93,237 | |
| Q_total | 730 | |

- T_total = angle circuits 79,480 (85%, forward + reverse) + outer state prep 846 + inner
  state prep 9,461 + Givens 2·75·(2·brot − 1) = 3,450.
- Q_total = 90 (state-prep persistent) + J·brot = 96 + max(544 state-prep temporary, angle
  temporary). **Angle-circuit workspace is free up to the 128-qubit cap**, since 544 dominates.
- Baseline shape: R, B, C = 65, 60, 60; brot = 12; J = 8; K = 10 circuits, each a plain QROM
  over L = 76 + R·B = 3,976 addresses (about 3,974 Toffolis each).
- The accuracy gates use the words the circuits actually load.
- E_SOS = ecore − η·β₁ − (Σ|λⱼ| − Σλⱼ) − ½ΣW² (negative eigenvalues of h1′).
- Circuits are XOR oracles run forward and then again in reverse (the same circuit both
  times), so the reverse pass can't be made cheaper separately.
- QROM break-early: a segment whose rows all hold the same delta costs no Toffolis. Row order
  within (ρ, b) is ours to choose, so sorting rows can exploit repeated or zero batches.

### Re-rounding the baseline angles to fewer bits

Naively rounding the baseline's 12-bit words fails the accuracy gates immediately:

| brot | error_1 (mHa) | error_2 (mHa) | λ_eff |
|---|---|---|---|
| 12 | 3.2 | 18.6 | 49.30 |
| 11 | 221 | 51.7 | 50.29 |
| 10 | 242 | 59.4 | 50.46 |
| 9 | 338 | 89.6 | 51.90 |
| 8 | 568 | 159 | 55.25 |

The jump at 11 bits (70× in error_1 for one bit) suggests the 12-bit words were optimized
at that precision rather than plainly rounded. Lowering brot will need the factorization
and words optimized together at the target precision.
